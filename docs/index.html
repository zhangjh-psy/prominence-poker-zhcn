PROMINENCE POKER · 简体中文汉化

安装教程：从打开网址到进游戏，一共 6 步

不需要懂技术，不需要注册账号。照着下面的截图点就行，全程约 3 分钟。

Windows 10 / 11 补丁版本 v1.0.1 12.2 MB 可一键还原英文

开始之前，只确认两件事

  • 游戏 已经装好，并且至少启动过一次（能正常进主菜单）。
  • 游戏已经完全退出。窗口关掉还不够，右下角托盘图标也要退出，任务管理器里搜不到 Prominence-Win64-Shipping.exe 才算干净。这一步不做，安装会失败。
1

2

点那个 12.2 MB 的 zip 文件

点一下就开始下载，几秒钟

文件名是 ProminencePoker-zhCN-v1.0.1.zip，后面标着 12.2 MB。点它，浏览器就开始下载了。

千万别点 Source code (zip) 或 Source code (tar.gz)。那是源代码包，里面没有安装好的文件，双击会提示「没有找到补丁数据」。有人就是点了这个才装不上的。

下载完成后，一般在浏览器的「下载」文件夹里，文件名大概长这样：

ProminencePoker-zhCN-v1.0.1.zip
3

解压这个 zip

右键 → 全部解压缩

找到刚才下载的 zip 文件，右键点它，选「全部解压缩…」（Windows 11 可能是「解压缩全部」），然后点「解压」。得到一个同名的文件夹，双击进去，里面应该是这些：

此电脑 › 下载 › ProminencePoker-zhCN-v1.0.1

README.txt
红框里这个「一键汉化.bat」——双击它
两个常见的错误：
① 不要在压缩包里直接双击 一键汉化.bat，必须先解压出来，否则文件找不到、会闪退。
② 不要把文件夹放进游戏安装目录（steamapps\common\Prominence Poker 里面）。放桌面、下载文件夹都行。放在游戏目录里会干扰 Steam 校验。
4

双击「一键汉化.bat」，输入 1 回车

会弹出一个黑底菜单窗口

双击那个 一键汉化.bat。会弹出一个黑色的命令窗口，显示这样的菜单：

C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe
  Prominence Poker  简体中文汉化补丁   v1.0.1
  ────────────────────────────────────────────

    1  安装汉化
    2  还原英文原版
    3  检查安装状态
    0  退出

  请选择: 1

在光标处输入数字 1，然后按 回车。程序会先自动找游戏安装位置，然后开始校验和写入。

如果它弹出一个选择文件夹的窗口，说明没有自动找到。这时候选到这一层：

D:\steam\steamapps\common\Prominence Poker

判断标准：这个文件夹里能看到 Prominence 这个文件夹和一个 Prominence.exe。选好后点「确定」。

5

等它跑完，看到「安装完成」就好了

大概 5～20 秒

正常情况下屏幕会输出这些内容，重点是最后出现 安装完成，共写入 44 个文件：

  ----------------------------------------------------
         游戏目录：D:\steam\steamapps\common\Prominence Poker

  正在校验补丁文件…
  [OK]   补丁文件校验通过（44 个文件）
  [OK]   已备份原始文件 44 个 → _zhCN_backup

  [OK]   安装完成，共写入 44 个文件。
  启动游戏即可看到中文界面。
  如需还原英文，再次运行本程序选择「还原英文」。
它同时会把原文件备份到游戏目录里的 _zhCN_backup 文件夹，所以随时能还原，不会破坏游戏本体。看到「按任意键继续」时按一下空格就行。
6

从 Steam 启动游戏

主菜单变成中文就成了

打开 Steam，正常启动游戏。主菜单应该显示「快速开始 / 查找比赛 / 商店与仓库 / 角色 / 排行榜 / 帮助与选项」。

这个游戏没有语言切换菜单，它是跟随系统语言加载的。所以只要你的 Windows 是中文，装的补丁就会生效，不需要在游戏里找选项。

如果主菜单还是英文，先别急，去下面的「装完还是英文」看两步排查。

出问题了？按现象对号入座

弹出蓝色的「Windows 已保护你的电脑」

这是 Windows 对没签名的小工具的标准提示，不是病毒。

点左边的 「更多信息」，出现「仍要运行」按钮，点它。如果按钮叫「运行」，直接点。

杀毒软件报警 / 直接把文件删了

汉化补丁改的是游戏资源文件，行为特征和某些恶意程序相似，360、火绒、Defender 经常误报。这是误报。

处理办法：把解压出来的整个文件夹加入杀毒软件的信任区 / 白名单，然后重新解压一次（文件被删了要重新解），再运行。

实在不放心，可以先关掉杀毒软件再运行，装完再打开。

窗口一闪就没了 / 双击没反应

大概率是解压位置不对，或者权限被挡。

① 确认文件已经完整解压到普通文件夹（不是压缩包里面，也不在游戏目录里）。

② 右键 一键汉化.bat → 以管理员身份运行。

提示「没有找到补丁数据」

说明你下的是源码包（Source code (zip)），不是发布包。

回到第 1 步，在这个页面里重新点 ProminencePoker-zhCN-v1.0.1.zip（12.2 MB 那个）。

提示找不到游戏 / 让你手动选文件夹

很正常，你的 Steam 库可能在非默认盘。手动选到这一层就行：

...\steamapps\common\Prominence Poker

判断标准：文件夹里能看到 Prominence 文件夹和 Prominence.exe。不要选到 Prominence 里面，也不要选到 Content 里面。

不确定游戏装在哪：Steam 库里右键游戏 → 管理 → 浏览本地文件，直接就到这一层了。

装完进游戏还是英文

按顺序查三件事：

① 游戏当时是不是真的退出了。最常见的原因是装的时候游戏还开着，文件被占用没写进去。完全退出后重装一次（选 1）。

② 再运行一次，选 3 检查安装状态。如果显示「文件匹配 44 / 44」，说明文件在，可能是加载问题，重启一次电脑再试。如果显示不匹配，说明被游戏更新覆盖了，重装。

③ 你的 Windows 系统语言如果不是中文，游戏可能会按系统语言走。这种情况下把系统语言临时改成中文再启动。

想变回英文原版

再运行一次 一键汉化.bat，在菜单里输入 2，回车。它会把备份的原文件复制回去。

如果备份被删了，也可以在 Steam 里右键游戏 → 属性 → 已安装文件 → 验证文件完整性，会把游戏恢复成官方原版（汉化也会一起没）。

Steam 更新游戏后，汉化没了

正常现象。游戏更新会覆盖被改过的文件。

重新运行 一键汉化.bat，选 1 再装一次就行。如果这次出现「文件不匹配」的提示，先选 2 还原一次，再选 1 安装。

游戏里有些字显示成方块或问号

说明字体文件没装上（被杀毒软件拦掉的可能性最大）。

先选 3 检查状态 看匹配数，再重新安装一次。仍然不行的话，把这个情况反馈给我，我发个字体修复包。
